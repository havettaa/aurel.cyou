Východiskový stav

Projekt obsahoval jednu MainActivity s textovým poľom a TextView v ScrollView. Po stlačení Enter sa zavolal endpoint /data/2.5/weather cez Retrofit s RxJava 3 adaptérom a odpoveď sa vypísala ako formátovaný JSON.

Modelové triedy pre odpoveď OpenWeatherMap (WeatherResponse, Main, Wind, Sys a ďalšie) a klient WeatherClientBuilder boli pripravené a použil som ich bez zmeny.

Cieľ nebol aplikáciu prepísať, ale rozšíriť ju tak, ako by sa rozširoval produkčný kód: s rešpektom k existujúcim knižniciam a štýlu.

Princípy riešenia

Každé mesto je samostatná jednotka

Má vlastný stav, vlastnú požiadavku a vlastnú chybu. Pomalé alebo neexistujúce mesto nezdrží ostatné.

Stav je vidieť vždy

Načítavanie, výsledok aj chyba majú v karte vlastnú podobu. Používateľ nikdy nepozerá na prázdnu obrazovku.

Logika bez Androidu je oddelená

Spracovanie vstupu, vyhľadávanie miest a formátovanie sú čisté Java triedy s unit testami.

Existujúci stack, žiadne experimenty

Java, RxJava, Retrofit a ViewBinding zostali. Pribudli len tri AndroidX knižnice.

Spracovanie vstupu

Vstup sa rozdelí podľa čiarok. Prázdne časti sa zahodia, medzery sa zjednotia a duplicity sa odstránia bez ohľadu na veľkosť písmen. Ponechá sa prvý zápis.

util/CityInputParser.java
public static List<String> parse(String input) {
    List<String> cities = new ArrayList<>();
    if (input == null) {
        return cities;
    }

    Set<String> seen = new HashSet<>();
    for (String part : input.split(",")) {
        String city = part.trim().replaceAll("\\s+", " ");
        if (!city.isEmpty() && seen.add(city.toLowerCase(Locale.ROOT))) {
            cities.add(city);
        }
    }
    return cities;
}

Nezávislé načítavanie

Najprv sa do LiveData pošle zoznam, v ktorom sú všetky mestá v stave LOADING, takže karty sú na obrazovke okamžite. Potom sa pre každé mesto spustí samostatná Rx reťaz. Keď odpoveď príde, nahradí sa len položka daného mesta.

WeatherViewModel.java
public void search(List<String> queries) {
    searchDisposables.clear();   // zruší požiadavky predošlého hľadania

    // Všetky mestá sa zobrazia hneď v stave načítavania.
    List<CityWeather> loading = new ArrayList<>();
    for (String query : queries) {
        loading.add(CityWeather.loading(query));
    }
    cities.setValue(loading);

    for (String query : queries) {
        load(query);
    }
}

private void load(String query) {
    searchDisposables.add(weatherClient
            .getWeather(query, UNITS, WeatherClientBuilder.WEATHER_APP_ID)
            .delaySubscription(debugDelayMs(), TimeUnit.MILLISECONDS)
            .firstOrError()
            .observeOn(AndroidSchedulers.mainThread())
            .subscribe(
                    response -> update(CityWeather.loaded(query, response)),
                    throwable -> update(CityWeather.failed(query, toError(throwable)))));
}

Debug oneskorenie. debugDelayMs() vráti náhodných 300 až 4000 ms, keď je BuildConfig.DEBUG pravda, inak 0. Vypnete ho konštantou DEBUG_RANDOM_DELAY. delaySubscription odloží samotné HTTP volanie, takže oneskorenie platí aj pre chybové odpovede.

public void bind(@NonNull CityWeather item) {
    this.item = item;

    CityWeather.State state = item.getState();
    binding.loadingIndicator.setVisibility(state == CityWeather.State.LOADING ? VISIBLE : GONE);
    binding.errorGroup.setVisibility(state == CityWeather.State.ERROR ? VISIBLE : GONE);
    binding.contentGroup.setVisibility(state == CityWeather.State.LOADED ? VISIBLE : GONE);

    switch (state) {
        case LOADING:
            showHeader(item.getQuery(), getContext().getString(R.string.loading_weather), null);
            break;
        case ERROR:
            showHeader(item.getQuery(), null, null);
            binding.errorMessage.setText(errorMessage(item.getError()));
            break;
        case LOADED:
            bindWeather(item.getResponse());
            break;
    }

Dopĺňanie miest

CityRepository načíta assets/cities.txt na IO vlákne (prázdne riadky a riadky s # preskočí). CitySuggestionAdapter filtruje cez CityMatcher: odstráni diakritiku cez Normalizer.Form.NFD, porovnáva bez ohľadu na veľkosť písmen a hľadá začiatok celého názvu aj každého slova.

util/CityMatcher.java
static String normalize(String text) {
    return Normalizer.normalize(text, Normalizer.Form.NFD)
            .replaceAll("\\p{M}", "")
            .toLowerCase(Locale.ROOT)
            .trim();
}

private static boolean matches(String city, String query) {
    if (city.startsWith(query)) {
        return true;
    }
    for (String word : city.split("[\\s-]+")) {
        if (word.startsWith(query)) {
            return true;
        }
    }
    return false;
}

Riešenie problémov

Sync hlási „Unsupported class file major version“

Gradle beží na príliš novom JDK. Nastavte Gradle JDK 17 podľa kroku 3.

Všetky mestá ukážu „Unable to load the weather“

API kľúč zo zadania (z roku 2023) mohol byť zrušený. V Logcate uvidíte HTTP 401. Vytvorte si bezplatný kľúč na openweathermap.org a nahraďte WEATHER_APP_ID v WeatherClientBuilder.java. Nový kľúč sa aktivuje až po chvíli.
